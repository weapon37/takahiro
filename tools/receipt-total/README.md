# receipt-total

領収書画像から読み取った合計金額を、Google スプレッドシートの指定セルに書き込むための一式。

- `Code.gs` — Google Apps Script のウェブアプリ。スプレッドシートへの書き込みを担当する。
- `write-total.mjs` — ウェブアプリを呼び出す Node スクリプト。依存パッケージなし。

## 仕組み

Apps Script を「自分として実行」でデプロイするため、自分が編集権限を持つスプレッドシートであれば
どれでも書き込める。月ごとに新しいシートやファイルを作っても、共有設定などの追加作業は発生しない。

書き込み先は毎回引数で指定する。スプレッドシート・シート名・セルのすべてを都度変更できる。

## セットアップ

一度だけ行う。

### 1. Apps Script プロジェクトを作る

1. https://script.google.com/ で新しいプロジェクトを作成する
2. `Code.gs` の内容をエディタに貼り付ける

### 2. 共有シークレットを設定する

十分に長いランダム文字列を用意する。

```bash
openssl rand -hex 32
```

Apps Script エディタの「プロジェクトの設定」→「スクリプト プロパティ」で、
プロパティ名 `SHARED_SECRET`、値に生成した文字列を登録する。

### 3. ウェブアプリとしてデプロイする

「デプロイ」→「新しいデプロイ」→ 種類は「ウェブアプリ」を選び、次のように設定する。

| 項目 | 値 |
| --- | --- |
| 次のユーザーとして実行 | 自分 |
| アクセスできるユーザー | 全員 |

「アクセスできるユーザー: 全員」は必須。これがないと Google のログイン画面が返ってきて
スクリプトが JSON を受け取れない。認証はシークレットで行っているため、URL とシークレットの
両方を知らなければ書き込みはできない。

初回デプロイ時に権限の承認を求められるので許可する。発行される `https://script.google.com/macros/s/.../exec`
の URL を控える。

### 4. 環境変数を登録する

```
SHEETS_WEBAPP_URL=https://script.google.com/macros/s/.../exec
SHEETS_WEBAPP_SECRET=手順 2 で生成した文字列
```

この 2 つは認証情報なので、リポジトリにコミットせず環境側の環境変数として設定する。

書き込み先が毎回同じスプレッドシート (タブだけが毎月増える台帳など) の場合は、既定値も登録しておく。
そうすると実行時にシート名とセルだけ指定すれば済む。

```
SHEETS_DEFAULT_SPREADSHEET=https://docs.google.com/spreadsheets/d/.../edit
```

スマートフォンから URL を調べるときは、Google スプレッドシートアプリで対象ファイルを開き
「⋮」→「共有とエクスポート」→「リンクをコピー」。共有設定を変更する必要はない。

### 5. 動作確認

```bash
node tools/receipt-total/write-total.mjs --inspect
```

シート一覧が表示されれば成功。

## 使い方

### シート名と現在値を確認する

シートは毎月変わるため、書き込み前に当月のシート名を確認できる。

```bash
node tools/receipt-total/write-total.mjs --inspect
```

```
スプレッドシート: 経費精算 2026
シート一覧: 2026-06, 2026-07, 2026-08
```

セルまで指定すると、そのセルの現在値も返る。

```bash
node tools/receipt-total/write-total.mjs --sheet 2026-08 --cell B12 --inspect
```

### 合計金額を書き込む

```bash
node tools/receipt-total/write-total.mjs --sheet 2026-08 --cell B12 --value 12480
```

```
書き込み完了: 経費精算 2026 / 2026-08 / B12
  (空) → 12,480 円
```

書き込み前の値も表示されるので、意図しない上書きに気づける。対象セルに数式が入っていた場合は
警告が出る。

### 書き込まずに結果だけ見る

```bash
node tools/receipt-total/write-total.mjs ... --dry-run
```

## 引数

| 引数 | 必須 | 説明 |
| --- | --- | --- |
| `--spreadsheet` | 任意 | スプレッドシートの URL または ID。省略時は `SHEETS_DEFAULT_SPREADSHEET` |
| `--sheet` | 任意 | シート名。省略時は先頭シート |
| `--cell` | 書き込み時は必須 | `B12` のような A1 形式。単一セルのみ |
| `--value` | 書き込み時は必須 | 金額。`12,480` のようにカンマ入りでも可 |
| `--inspect` | 任意 | 書き込まず、シート一覧と現在値を返す |
| `--dry-run` | 任意 | 書き込まず、書き込み結果の見込みを返す |

## 注意点

- 書き込めるのは単一セルのみ。範囲指定はエラーになる。
- 指定したシートが存在しない場合、利用可能なシート名の一覧がエラーメッセージに含まれる。
- `SHEETS_WEBAPP_SECRET` が漏れると、URL を知る第三者が書き込める。漏れた場合は
  スクリプトプロパティの値を変更すれば無効化できる。
