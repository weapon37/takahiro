  台本の締め・テロップ・概要欄は必ず「毎週金曜7時」と書くこと。
  ⚠ 曜日は必ず実日付から検算する。2026/8/1は土曜で、`week2_publish.md` の
  「月〜日」表記は実際の曜日と一致していない(7日間の並びを表す汎用ラベルだった)
- 職業別シリーズはライター編(8/3・3時間で1,980回・登録+1)で実績あり。
  w3i(経理編)の結果を待たずに伸ばしてよい軸

## この配分にした理由

**持論型を3本に抑えた。** w3g/w3hの判定(50%超なら武器 / 40%未満ならランキング中心へ)が
まだ出ていないため。3本なら、40%未満という結果が出ても差し替えで吸収できる。
逆に50%超なら、Week5で本数を増やせばよい。

**職業別を3本入れた。** これはw3i(経理編)の結果を待つ必要がない。
ライター編の実績が先にあるため、根拠が独立している。
既出は営業・事務(Week1)、ライター・デザイナー(Week2)、経理(Week3)。
今回は人事・採用 / 教員・講師 / 店舗・小売で、いずれも未出かつ視聴者層が厚い。

**署名回を2本に増やした。** Week3ではw3c 1本のみ。差別化の核なので厚くする。
11番はツール紹介型にして、署名性とランキング型の相性を確かめる。

**朝はランキング、夜は持論**というWeek2の並びを基本にしたが、持論が3本しかないので
夜の3枠はランキングが入る。

## データが出たら差し替える候補

8/13にWeek3の数字が出るので、**制作着手前に以下だけ確認して調整する**。

| Week3の結果 | Week4での対応 |
|---|---|
| 持論型が40%未満 | #2/#6/#10 のいずれか2本を🏆に差し替え(職業別か署名回を追加) |
| 持論型が50%超 | このまま。Week5で持論を増やす |
| 職業別(w3i)が不調 | #8/#12 を減らし、チャンネルの核か誠実路線に振る |
| 3〜8秒の谷が残っている | **全12本のフックを2シーンに分割する**(w2d7_am_news2 と同じ構造)。
これは配分ではなく作り方の問題なので、どの台本にも効く |

谷の判定には、8/7のニュース回(フック分割済み・4.4秒でテロップ切替)と
Week3のランキング6本(フック7.3〜8.3秒・据え置き)の比較が使える。

1. **#3 週刊ニュース以外を先に作る。** ニュースは8/14当日の朝に出すため、
   **8/13中に書いて仕上げる**必要がある(取材範囲は8/8〜8/13)。他を先に片付けておく。
   金曜固定にしたことで締め切りがWeek3のデータが出る日と重なる点に注意
2. 職業別3本(#1/#8/#12)は構造が同じなので連続で作ると速い
3. 署名回2本(#5/#11)は自作素材(own_camera系)が主役。素材の割り当てを先に決める
4. 持論3本(#2/#6/#10)は差し替え候補なので最後に回す

## 各本の注意

- **#7**(`w4h_uita`)はチャンネルの核メッセージ(w3aの1位「空いた時間を埋める」)の裏返し。
  w3aが「埋めてしまう失敗」、#7が「実際にどう使うか」。1位を「何もしない時間にする」に
  したのは、すぐ埋めるなというw3aの結論と揃えるため
- **#4**(`w4e_koukai`)は誠実路線(w3b)の続き。**特定ツールを名指しで否定していない。**
  共通点を使い方の問題として構成した
- **#9**(`w4i_asai`)はw3e(指示に足す3つ)の続編。w3eは「最初に足す」
  (誰に向けて/長さ/悪い例)、#9は「答えが浅かったときに足す」(具体例/根拠/反対意見)で
  重複しないよう分けた
- **#11**(`w4k_shashin`)はWeek2の動画編集AI回と重複しないよう写真の後処理を軸にした。
  CapCutは2位に留め、1位は商用利用の安心を理由にAdobe Firefly
- **#6**(`w4g_jitanowari`)の対立軸は「埋める/空ける」。当初「埋める/決める」にしていたが、
  『埋める』は時間の使い方、『決める』は事前の段取りで軸が揃っていなかった。
  『空ける』の具体は「早く終わったら早く終わりにする」(=浮いた分を仕事に返さない)。
  **⚡のvsは必ず同じ軸の対になっているか確認すること。**
- ⚡3本はフックを分割していない。元々4〜5秒と短く、Week3の持論2本と同条件で
  比較するため。🏆側だけ2分割している
- **実測値はどの台本にも入れていない。** このチャンネルで実際に測ったのは経理編の
  freee請求書(36分10秒→3分10秒)だけのため。数字を出すなら実際に測ったものだけ
- 人事編・教員編には個人情報をAIに入れない注記を本編と概要欄の両方に入れている
