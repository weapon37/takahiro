# 撮影オーダー表（自作背景素材）

チャンネル「仕事が消えるAI帳」の背景は **文ごとに内容と一致させる**（`bg_sync_map.md` 参照）。
そこで必要になるのは「意味を背負える絵」。以下は使用頻度の高い順の撮影リスト。

## 共通の撮影仕様

| 項目 | 指定 |
|---|---|
| 向き | **縦**（1080×1920想定。最終的に720×1280へ変換） |
| 尺 | **6秒以上**（使うのは頭6秒。長めに回してOK） |
| 動き | **ゆっくり**。固定 or 微速パン／寄り。速いブレは不可 |
| 構図 | **中央〜上部を空ける**（テロップが乗る）。被写体は下寄せか左右どちらかに |
| 明るさ | 明るめ。暗所は粒状感が出る |
| HDR | オンのままでOK（こちらで npl=1000 でナチュラルに変換） |
| 音 | 不要（背景は無音で使用） |

## 🔴 最優先（毎回のように出番がある）

**「AIで作業が速くなる」を語る動画の主役カット。今いちばん不足している。**

1. **タイピングの手元** — キーボードを打つ手。斜め45度／真上から。速めのタイプが良い
2. **スマホを操作する指** — スクロール、タップ。画面の中身は写らなくてよい
3. **ペンでメモを書く手** — ノートに書く。手書き＝「人が考える」象徴
4. **マウス操作／トラックパッド** — 細かい作業感
5. **PCを開く／閉じる** — 仕事の開始・終了の合図として使える
6. **書類をめくる・積む** — 事務作業の象徴（経理・請求書の回で必ず要る）

## 🟡 高頻度（時間・段取りの比喩）

7. **時計（秒針が動く）** — アナログ推奨。「36分→3分」の実測回に必須級
8. **カレンダーをめくる／書き込む** — 予定・締切
9. **朝の光が差し込む部屋・机** — 一日の始まり
10. **コーヒーを淹れる → 飲む**（※`own_coffee_pour`で一部確保済み）
11. **砂時計・タイマー** — 時間切れ・締切の緊張感

## 🟢 元カメラマンの署名カット（差別化の核）

**他のAI系発信者が絶対に持っていない絵。ここが最大の武器。**

12. **三脚を立てる／カメラを構える** — 手元のアップ（`own_camera`は遠景なので寄りが欲しい）
13. **レンズを交換する・絞りリングを回す** — 機材の質感
14. **ファインダーを覗く横顔**（顔が写らない角度で） — 職人感
15. **撮影データをPCに取り込む** — 「昔＝手作業／今＝AI」の対比に使える

## 🔵 対比・情景（あると表現の幅が出る）

16. **散らかった机 → 片付いた机**（同じ構図で2カット） — ビフォーアフターに直結
17. **付箋がびっしり貼られた画面／ボード** — タスク過多の象徴
18. **歩く足元**（自分の足を見下ろす） — 「続ける」の比喩
19. **電車の窓から流れる景色** — 移動・通勤
20. **夜のデスク（照明ひとつ）** — 残業・締切前

## 撮り方のコツ（テロップと相性を良くする）

- **中央を空ける**：被写体を画面の下1/3、または左右どちらかに寄せる。中央〜上部はテロップ帯が乗る
- **背景をシンプルに**：柄物・文字（ロゴ、書類の文面）が写ると視線が散る。生活感のある物は避ける
- **同じ被写体で寄り／引きの2カット**：1文=2カットの構成に使いやすい（前半＝引き、後半＝寄り）
- **動きは一方向に**：往復させず、寄るなら寄りきる。途中で止めない
- **10秒くらい回す**：頭2〜3秒は手ブレしがちなので、使う分の前後に余裕を

## 個人情報・身バレ対策

- **顔・表札・車のナンバー・書類の文字**は写さない
- 手元カットは**時計・指輪・特徴的な服**が写り込まないように（毎回同じだと特定材料になる）
- 屋外は**近所が特定できるランドマーク**を避ける

## 納品方法

このチャットに動画を貼るだけ。こちらで以下を自動処理します：
1. HDR→SDRをナチュラル発色で変換（npl=1000）
2. 720×1280に切り出し
3. `public/bg/own_*.mp4` として登録
4. `bg_sync_map.md` の語彙表に意味づけして追記
