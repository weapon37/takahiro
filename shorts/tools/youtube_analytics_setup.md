# YouTube Analytics 自動取得のセットアップ(初回のみ・上杉さんの作業)

分析データの自動取得には、YouTubeチャンネルの持ち主本人によるログイン許可(OAuth)が必要です。
これはAPIキーだけでは代用できず、Google Cloudコンソールでの設定+ブラウザでの1回の許可操作が必要です。
以下の手順を、チャンネルにログインしているGoogleアカウントで行ってください。

## 1. Google Cloudプロジェクトを作る

1. https://console.cloud.google.com/ を開く(初めてなら利用規約に同意)
2. 上部の「プロジェクトを選択」→「新しいプロジェクト」→ 名前は何でもよい(例: `shigoto-kieru-ai-analytics`)→作成

## 2. APIを2つ有効化する

1. 左メニュー「APIとサービス」→「ライブラリ」
2. 「YouTube Analytics API」を検索→有効にする
3. 「YouTube Data API v3」を検索→有効にする

## 3. OAuth同意画面を作る

1. 「APIとサービス」→「OAuth同意画面」
2. User Type は「External」を選択→作成
3. アプリ名(何でもよい)・ユーザーサポートメール・デベロッパー連絡先メールを入力→保存して次へ
4. スコープの追加は不要、そのまま次へ
5. 「テストユーザー」に、チャンネルを管理しているGoogleアカウントのメールアドレスを追加→保存

## 4. OAuthクライアントIDを発行する

1. 「APIとサービス」→「認証情報」→「認証情報を作成」→「OAuthクライアントID」
2. アプリケーションの種類は **「TVとその他」(TVs and Limited Input devices)** を選択
3. 名前は何でもよい→作成
4. 表示された **クライアントID** と **クライアントシークレット** をメモする(この2つを次で使います)

## 5. 私(Claude)に伝える

クライアントIDとクライアントシークレットを教えてください。私の方で以下を実行し、表示されるURLとコードをお伝えします。

```
GOOGLE_OAUTH_CLIENT_ID=<クライアントID> GOOGLE_OAUTH_CLIENT_SECRET=<シークレット> \
  .venv/bin/python tools/youtube_auth.py
```

## 6. ブラウザで許可する

1. お伝えするURL(`google.com/device` など)をスマホかPCのブラウザで開く
2. 表示されたコードを入力
3. チャンネルを管理しているGoogleアカウントでログイン→許可

これで完了です。以後は `tools/youtube_report.py` を実行するだけで、再生数・視聴維持率・いいね・コメント数・登録者増分が自動で一覧表示されます(認可は基本的に無期限に有効。取り消した場合のみ再度この手順が必要)。

## 注意

- クライアントシークレットは秘密情報です。このチャットで送っていただいて大丈夫ですが、リポジトリには一切コミットしません(`tools/.youtube_token.json`は`.gitignore`済み)。
- 「テストユーザー」のままだとOAuth同意画面は「本番公開」扱いになりませんが、自分のアカウントだけが使うツールなので問題ありません(Googleの審査は不要)。
