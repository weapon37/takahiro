# キャラクターデザイン仕様書
## 「ダメ出しシューヘイ」

---

## 基本設定

| 項目 | 内容 |
|---|---|
| キャラ名 | ダメ出しシューヘイ |
| チャンネル名 | シューヘイのAI現場ダメ出し |
| モチーフ | 実在した愛犬（ジャック・ラッセル・テリア）をベースにしたAIキャラ ※実名は使用しない |
| 役割 | 「AIツールは使えるが、自分の仕事・場面に落とし込めていない」視聴者に、毒舌・ツッコミでズバッと切り込む案内役 |

---

## 見た目の仕様（参考写真より）

| 部位 | 特徴 |
|---|---|
| 犬種 | ジャック・ラッセル・テリア |
| 毛質 | ワイヤーコート（ゴワゴワ・もじゃもじゃした剛毛質感） |
| 毛色 | 白ベース＋茶色と黒のまだら模様。顔周り・両耳・尻尾の付け根に配色が集中 |
| 耳の形 | 立ち耳。左右非対称（片方はまっすぐ立ち、もう片方はやや前に折れる） |
| 表情 | 舌を出して笑っているような人懐っこい表情がデフォルト |
| 尻尾 | 先端が白、付け根が茶色。動きの演出に使いやすい長さ |
| 体格 | 中型〜小型犬。全体的に細身でアクティブな体つき |

---

## キャラクター性

| 項目 | 内容 |
|---|---|
| 性格 | 元気でやんちゃ、遠慮なく本音を言う |
| 話し方 | 少し毒舌・ツッコミ口調。テンポ良く、記憶に残るフレーズを使う |
| 決め台詞 | 「わん、それ落とし込めてないよね」 |
| 距離感 | 上から目線の先生ではなく、ズバッと言ってくる身近な相棒・同僚のような立ち位置 |

---

## アニメーション演出の方向性（Remotion実装向け）

- ワイヤーコートのモサモサ感を活かし、喋る・驚く動作で毛が揺れる演出と相性が良い
- 非対称な耳は「ツッコミ時にピンと立つ／呆れた時に片耳だけ垂れる」等、感情表現の可動パーツとして使える
- 尻尾の動きで「テンポの良さ」「機嫌の良し悪し」を視覚的に表現しやすい
- 舌を出した表情をデフォルトの「笑顔」ベースとして、ダメ出し時は口を「への字」に変化させるパターンを想定

---

## ナレーション実装メモ

- Google TTSでの音声は、テンポの良い区切り（短文・体言止め多用）で毒舌感を演出
- 語尾に「わん」を軽く挟む口癖を台本テンプレートに組み込む
- 動画末尾のCTA（cta_variants.json）とキャラの口調を統一させる
