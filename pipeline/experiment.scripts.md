## 台本

### 損失型か利益型か  (`p1-loss-vs-gain`)

**共通テーマ**: AIに任せる判断をまちがえると時間が増えてしまう仕事

#### 1日目 / 2026-08-10 / A案「損失型」

**タイトル**: AIに任せると逆に損する仕事3つ

**条件**: 尺30秒 / 3項目 / 答えは冒頭3秒 / CTA:none / loss / 金額:none / 対象:task_based

```
毎日メールに1時間使っている人へ。AIに投げると逆に10分損する仕事、1つ目は謝罪メールです。言い回しを直す時間で、自分で書くより長くかかります。2つ目は、口頭で受けた依頼のメモ。前提を説明する手間のほうが大きい。3つ目は、数字の最終チェック。合っているか確かめ直す二度手間で、時間を失います。この3つを投げている人は、毎日30分損しています。AIに渡すのは、手順が決まった作業だけにしてください。
```

#### 2日目 / 2026-08-11 / B案「利益型」

**タイトル**: AIに任せると10分戻る仕事3つ


## 使いかた

この台本は**レビュー用の下書き**。パイプラインを普通に動かすと、
昼の枠が来たときに Claude が同じ条件で台本を作るので、この14本がそのまま使われるわけではない。

- そのまま使いたい → 各回の `work/<job_id>/script.txt` を、上の台本に差し替えてから動画生成へ進む
- 生成に任せる → 何もしなくてよい。条件は自動で入る

公開から48時間後に実測値を入れる:

```bash
python3 pipeline.py --record 2026-08-10 --views 820 --avg-view-pct 58.4 --retention-5s 91.0
python3 pipeline.py --experiment-report
```
