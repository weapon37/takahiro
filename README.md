# 領収書 → freee 自動入力ツール

領収書・レシートの画像をアップロードすると、Claude (Anthropic API) が内容を読み取り、
freee(会計freee)の取引入力に必要な項目を自動で推定するツールです。

読み取る項目:

- 発生日 / 支払先 / 税込金額
- 勘定科目(旅費交通費・消耗品費・接待交際費など、`src/lib/expense-categories.ts` 参照)
- 税区分(課税仕入10% / 軽減8% など)
- 品目 / 備考 / 読み取り確信度

複数枚をまとめてアップロードでき、結果は編集可能な表で確認・修正したうえで、
freeeの「取引の一括登録(インポート)」に取り込める CSV としてダウンロード/コピーできます。

## セットアップ

```bash
npm install
cp .env.example .env.local
# .env.local に ANTHROPIC_API_KEY を設定
npm run dev
```

[http://localhost:3000](http://localhost:3000) を開いて領収書の画像をアップロードしてください。

## 使い方

1. 領収書・レシートの画像をドラッグ&ドロップ(または選択)。最大10枚まで。
2. 「領収書を読み取る」を押すと、各画像をAIが読み取り、表に一覧表示します。
3. セルをクリックして日付・勘定科目・金額などを修正できます。
   - AIの読み取り確信度が低い行(黄・赤バッジ)は特に確認してください。
4. 「freee用CSVをダウンロード」で、Excel互換(BOM付きUTF-8)のCSVを出力。
   freeeの取引インポート画面で列を対応づけて取り込みます。

> 注意: AIによる読み取りは自動化の補助です。金額・日付・勘定科目は必ず目視で確認してから
> freeeへ登録してください。

## 構成

- `src/lib/expense-categories.ts` — 勘定科目・税区分の定義
- `src/app/api/receipt/route.ts` — 画像を受け取りClaude APIで経費項目を抽出するAPIルート
- `src/components/ReceiptForm.tsx` — アップロードUI・編集テーブル・CSV出力

## 今後の拡張(任意)

freee API を使って取引を直接登録することも可能です。その場合は freee でアプリを登録し、
OAuth2 認可(クライアントID/シークレット、リフレッシュトークン)を設定する必要があります。
