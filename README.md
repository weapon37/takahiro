# バズったX投稿 量産ツール

バズったX(旧Twitter)投稿のテキストまたはスクリーンショットを入力すると、Claude (Anthropic API) が投稿の「型」(共感・感情訴求型、ノウハウ・Tips型、ストーリー型など12種類、`src/lib/post-types.ts` 参照)を判定し、同じ型・構成・フックを踏襲した新しい投稿をまとめて生成します。

生成した投稿は、指定したターゲット・ジャンルに合わせた内容になります。まとまった時間が取れるときに一度に量産し、CSVで書き出して予約投稿ツールに流し込む使い方を想定しています。

## セットアップ

```bash
npm install
cp .env.example .env.local
# .env.local に ANTHROPIC_API_KEY を設定
npm run dev
```

[http://localhost:3000](http://localhost:3000) を開いてください。

## 使い方

1. 画面上部の「投稿するジャンル」からプリセットを選ぶ(初期値はランニング / サブ4を狙う市民ランナー)。プリセットをそのまま編集すればカスタム設定になり、内容はブラウザに保存されて次回も引き継がれます。
2. バズった投稿の本文を貼り付けるか、スクリーンショットをアップロードする。
3. 生成する数を選んで「投稿を量産する」。
4. 結果を「全てコピー」またはCSVで書き出す。CSVには投稿予定日が翌日から1日1件で入るので、表計算ソフトで調整してから予約投稿ツールに取り込めます。

## 構成

- `src/lib/post-types.ts` — 投稿の型の定義一覧
- `src/lib/personas.ts` — ターゲット・ジャンルのプリセット定義
- `src/lib/csv.ts` — 量産結果のCSV書き出し
- `src/app/api/generate/route.ts` — 入力を受け取りClaude APIで分析・生成するAPIルート
- `src/components/PostGeneratorForm.tsx` — 入力UIと結果表示

## 生成される投稿についての注意

生成結果はそのまま投稿できる形ですが、投稿前に必ず自分で確認してください。

- アフィリエイトリンクを含む投稿には、景品表示法(ステマ規制)により投稿単位で「PR」「広告」の表記が必要です。
- 成果や効果を断定・保証する表現、サプリメントや器具の健康効果に関する表現は、景品表示法・薬機法に触れるおそれがあります。プロンプト側でも避けるよう指示していますが、最終確認は投稿者の責任で行ってください。
